Project: 3D Calcium Imaging Denoising (AI4Life International Grand Challenge)
- Context & Challenge: Volumetric (3D) calcium imaging of live biological cells requires extremely low light to avoid phototoxicity (damaging or killing the live cells). This results in massive visual noise. Standard supervised learning is impossible because obtaining a clean "ground truth" reference image physically destroys the cellular sample.
- Denoising Pipeline Architecture: Developed a self-supervised image restoration pipeline to denoise volumetric microscopy data. It utilizes a 3D Noise2Void (N2V) neural network built in PyTorch. The pipeline loads high-dimensional 3D TIFF stacks, applies a mathematical blind-spot masking algorithm (excluding random pixels during training), and forces a 3D UNet encoder-decoder architecture to predict the missing values based strictly on spatial neighborhoods. Because cellular structures are continuous while noise is mathematically random, the network learns to ignore noise and extract clean biological signals.
- Evaluation Metrics: The pipeline's performance is rigorously measured using stSNR (spatio-temporal Signal-to-Noise Ratio), PSNR (Peak Signal-to-Noise Ratio), and Scale-Invariant PSNR (SI-PSNR).
- Deployment & DevOps: Containerized the entire PyTorch pipeline using Docker to ensure perfect reproducibility and smooth execution on the Grand Challenge platform, which led directly to achieving Global Rank 2.
- GitHub Repository: https://github.com/chhayanshporwal/3d-n2v-calcium-denoising

Project: CallSentry (Android Application)
- Context & Challenge: Standard Android privacy and call blocking applications are often built using cross-platform wrappers or route private logs through external servers, posing latency and security risks. CallSentry provides strict local Whitelist/Blocklist filtering and emergency breakthrough rules on-device.
- App Architecture: CallSentry is a system-level Android application built natively in Kotlin. It registers low-level Broadcast Receivers and Notification Listener Services to monitor incoming telephony states. Project: AI Wedding Image Culling System
- Context & Challenge: Event photographers waste days manually reviewing thousands of raw burst photos to delete blurry, blinking, or duplicate photos. This system automates the culling process via a high-throughput computer vision pipeline.
- Pipeline Architecture: The pipeline orchestrates specialized AI models in a multi-stage sequence:
  1. Mathematical Pre-filtering: Calculates the variance of the Laplacian of each image. If the sharpness falls below a strict mathematical threshold, the image is immediately rejected as blurry, saving GPU overhead.
  2. Subject Validation: Uses YOLOv8n to confirm that human subjects are present and represent the focal point.
  3. Quality Check: Maps facial landmarks using MediaPipe FaceMesh to detect closed eyes, bad exposure, and poor expressions, routing low-quality frames to a reject bin.
  4. Semantic Clustering: Generates 768-dimensional vector embeddings for the surviving images using OpenAI's CLIP (ViT-L/14) model. The system computes the L2 distance between embeddings to group near-identical burst shots and selects the single highest-scoring image from each cluster.
  5. VIP Preservation: Cross-references faces against enrolled VIPs (e.g., Bride and Groom) using FaceNet and MTCNN. VIP photos are prioritized and always preserved regardless of default culling algorithms.
- Backend Tech Stack: Built using FastAPI. FastAPI's asynchronous routing allows massive batch processing of image galleries without blocking or locking up the Python backend server during GPU inference.
- GitHub Repository: https://github.com/chhayanshporwal/AI-Wedding-Culling-Suite
